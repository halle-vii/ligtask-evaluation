Methods, exclusions, and limitations

Each model is analyzed separately using one finished saved run. The same base query is the repeated unit across the 12 conditions. Only complete sets enter each outcome's analysis; no values are filled in, and results from different runs are not pooled. The 30-base minimum is an application readiness rule, not a statistical power guarantee.

Correctness uses binomial generalized estimating equations (GEE), clustering on base query, with sum-coded factors, independent working correlation, and bias-reduced covariance. Each effect uses a joint Wald chi-square test. It is not labeled ANOVA because correctness is binary.

Model safety ratings use balanced repeated-measures ANOVA with an effect-specific Greenhouse–Geisser correction to the degrees of freedom. This treats the 1–10 ratings as approximately continuous. Review the contrast-residual diagnostics and this assumption before thesis reporting. The residual diagnostic is the smallest Shapiro–Wilk p-value among an effect's contrast dimensions; it is not an automatic pass/fail decision.

Holm adjustment covers 98 planned tests: seven effects × seven models × two outcomes. Unavailable tests remain in the family with p = 1. Missing inputs, insufficient samples, zero error variance, singular covariance, or failed fits show N/A.

The implemented methods clarify the manuscript's three-factor analysis for repeated queries. Confirm these statistical-treatment details with your adviser before using the results as final thesis findings. Follow-up pairwise comparisons are not included in these omnibus tables.
